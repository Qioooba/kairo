## 3. 接口契约

### 3.1 新增端点

| Method | Path | 用途 |
|--------|------|------|
| POST | `/api/files/preview` | 文件前 N 字节预览（限 1-10MB） |
| POST | `/api/local/reveal-file` | 按绝对路径在文件管理器中显示 |
| POST | `/api/local/open-folder` | 按绝对路径打开目录 |
| POST | `/api/downloads/{name}/open-dir` | 按下载文件名 reveal（v0.5-F 简版） |

### 3.2 升级端点

| Method | Path | 升级 |
|--------|------|-----|
| POST | `/api/files/list` | 加 `targets[]`（多 server × path）；保留 `servers[]`（共用 path）和 `server`（单 server，向后兼容）|
| POST | `/api/logs/search/multi` | 加 `targets[]` + `file_patterns[]`；query string 加 `since` / `until` 时间窗口 |
| POST | `/api/files/download` | 加 `target_dir`（绝对路径；空走默认 download_dir）|
| POST | `/api/logs/tail/start` | 不变（独立窗口用） |
| GET  | `/api/logs/tail/{id}/events` | SSE 流不变（独立窗口用） |
| POST | `/api/admin/servers` | 不变（v0.5-A 修过 GBK / state 持久化） |

### 3.3 数据契约

- `dlmanager.Item` 加 `abs_path` 字段（绝对路径，前端可拼"打开"按钮）
- `logsSearchMultiReq` 加 `targets` / `file_patterns` 字段
- `filesListReq` 加 `targets` 字段
- `filesDownloadReq` 加 `target_dir` 字段
- `filesPreviewReq` 新加

## 5. 已知限制

- 文件预览默认 1MB、上限 10MB（防爆内存）；大文件要看完整请用「下载」+「预览」组合
- 通知栈最多同屏 4 条（多了会自动堆到下面）
- fixed 底部栏假设 sidebar 240px；如果改 sidebar 宽度需要同步改 left
- `/api/files/preview` 不支持目录预览（前端有提示）
- `tier-badge` 配色：紫/绿/黄（dark + light 主题各一套变量）

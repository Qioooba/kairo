### 问题 #001 - URL encode 输入格式要求不明确

| 属性 | 值 |
|------|------|
| **编号** | #001 |
| **模块** | 报文格式化 |
| **页面/按钮/接口** | `/api/format/url-form` |
| **严重程度** | 低 |
| **发现时间** | 2026-06-28 |

**复现步骤**:
1. 打开报文格式化页面
2. 输入 `{name":"test","value":123}` （数字类型）
3. 点击 encode 按钮

**实际结果**:
- 返回 400 Bad Request
- 错误消息: "encode 模式 input 必须是 JSON 对象字符串"

**期望结果**:
- 输入数字类型的 value 时，应自动转为字符串
- 或错误消息应说明 value 必须是 string 类型

**截图路径**: `test-results/screenshots/`

**修改建议**:
1. 在 encode 前验证输入格式，给出更明确的错误提示
2. 或自动转换 number 类型为 string

**状态**: 待修复

|------|------|

| **模块** | 文件下载 |

| **严重程度** | 中 |
| **发现时间** | 2026-06-28 |

**复现步骤**:
1. 打开文件下载页面
2. 选择业务系统（如"信贷生产（模拟）"）

- 选择系统后，服务器下拉框仍为 disabled
- 即使系统下有服务器配置

**期望结果**:

- 显示该系统下的服务器列表

**截图路径**: `test-results/screenshots/`

**修改建议**:
1. 检查系统选择事件处理逻辑
2. 确保服务器列表在系统选择后更新
3. 确保下拉框在有可用服务器时启用

**修改建议**:
1. 在 tab 切换时调用 stop tail API
2. 使用 React useEffect cleanup 清理 SSE

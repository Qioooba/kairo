## 二、实现要点

### #19 主题切换接入

**反 FOUC**: index.html `<head>` 内联 script 在 CSS 加载后、CSS 应用前就读 localStorage 设 `data-theme`，避免刷新时先按 `prefers-color-scheme` 闪一下再切到本地选择。

```html
<script>
  (function () {
    try {
      var t = localStorage.getItem('dtb_theme');
      if (t !== 'dark' && t !== 'light') t = 'dark';
      document.documentElement.setAttribute('data-theme', t);
    } catch (_) {
      document.documentElement.setAttribute('data-theme', 'dark');
    }
  })();
</script>
```

**theme.js**: 不耦合顶栏 DOM 结构 — 切主题时 dispatch `dtb:themechange` 事件；button emoji 由 init() 兜底更新。

### #3 保存按钮位置

**两层 save**: 顶部（btnRow 内）+ 底部（editorCard 后，sticky）。共用 `doSave()` / `doReset()`，由 `syncSaveBtns()` 同步 `state.dirty` 到 `disabled` 属性。btnSave 始终带 `btn-primary` 样式 — 用 disabled 而不是 class 切换表示 "无未保存改动"。

```js
const syncSaveBtns = () => {
  const top = $('#cfg-save-btn');
  if (top) top.disabled = !state.dirty;
  document.querySelectorAll('.cfg-save-footer').forEach(b => { b.disabled = !state.dirty; });
};
```

### #4 系统 tag 横排

CSS 改 `grid-template-columns: auto`（之前 36px 固定列被 min-width:40px 撑爆，文字被竖排），加 `box-sizing: border-box` + `display: inline-block`。

### #5 配置页 UX

- **复制按钮说明**: editorCard 描述加 `.card-desc-extra` 解释"系统行的复制=复制整个业务系统"和"服务器行的复制=复制该服务器（含其全部日志目录）"
- **文件名规则 placeholder**: 改成多行示例，含 glob 通配符说明（`*.log`, `error_*.txt`）
- **未实现**："跨服务器复制日志目录"按钮（额外新增交互，超出本次任务范围；用户在 description 里已能理解现有复制按钮的语义）

内网 WebSphere 维护痛点：日志散落多台机器、tail 不实时、SSH 工具又笨重。Kairo 把"日志搜索 / 文件下载 / 报文格式化 / 常用命令速查"塞进一个本地 Web 界面。

🚀 快速开始

方式 A：双击发版 exe。方式 B：开发模式 go run .。

🛠 技术栈

Go 1.22 / Wails（备选）/ 内嵌 WebView + vanilla JS。Win 7 兼容走 Go 1.20.x + go-keyring 旧分支。

🏗 架构

四层：Web (vanilla JS) → HTTP API → internal/... → SSH client / File / Config。

产品概览 新

内网 WebSphere 维护痛点：日志散落多台机器、tail 不实时、SSH 工具又笨重。Kairo 把"日志搜索 / 文件下载 / 报文格式化 / 常用命令速查"塞进一个本地 Web 界面。

设计哲学 新

为什么选 Wails / Go / 内嵌 WebView？为什么不直接搞 Electron？取舍点：包体积（10MB vs 100MB+）、启动速度、内网零依赖、Win 7 兼容性。每一条都有明确 trade-off，不为"现代"而现代。

四层架构 改

分层：Web (vanilla JS, 零构建) → HTTP API → internal/... → SSH client / File / Config。每一层职责单一、可独立测试、不允许跨层调用。

技术栈

Go 1.22 / 内嵌 WebView + vanilla JS。Win 7 兼容走 Go 1.20.x + go-keyring 旧分支。前端零构建，所有逻辑在浏览器原生 JS 里跑。

安全白皮书 改

威胁模型：恶意前端输入 / 中间人 / 凭据泄漏 / 任意文件下载。缓解：凭据走后端 keyring、不进前端；free_file_roots 白名单；SSH 主机指纹校验；fail-closed 默认配置。

SSH 兼容 新

OpenSSH 6.2p2 / AIX / WebSphere SSH 兼容矩阵：3 套 profile 自动 fallback、keyboard-interactive 认证、握手 deadline 与 ctx 分离。详见 docs/SSH-TERMINAL-DESIGN.md。

质量保障 改

mock_sshd + fake-websphere Python helper；Playwright E2E 16 项修复回归；前后端单测 + 集成测试 + 覆盖率。CI 辅助脚本确保不漏项。

功能模块 改

9 大功能卡片（WebSphere 日志 / 文件下载 / 报文格式化 / HTTP 测试 / 代码比对 / 常用命令 / 环境自检 / 下载历史 / 系统配置）+ 4 个小工具（时间戳 / Cron / JSONPath / 关于）。

横向对比 新

和 kibana / ssh-cli / postman-desktop / windterm 的对比。Kairo 不替代它们，而是"在不能用 GUI 工具的内网 + 必须管 WebSphere 的场景下"的最佳折中。

故障复盘 新

踩过的坑：OpenSSH 6.2p2 握手 hang、keyring 在 Linux headless 容器下不可用、Win 7 下 emoji 字体缺失、xterm.js Canvas 渲染在老显卡白屏。每次都有"现象 → 根因 → 修复 → 验证"四段。

版本史 改

v0.10（开发中）、v0.9.0（当前）、v0.8 / v0.7 / v0.6 / v0.5 / v0.4 / v0.3 / v0.2 / v0.1 历史。每个版本一行总结 + 关键 commit 链接。

路线图

v0.11+ 多用户 RBAC、v0.12 远程协作、v1.0 完整产品化。优先级由"内网同事实际需求"驱动，不是"feature 列表"驱动。

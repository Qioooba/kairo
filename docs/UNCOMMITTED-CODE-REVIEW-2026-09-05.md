# 未提交代码审查与修复（2026-09-05）

本轮范围包含当前工作区全部待提交代码：数据库工作台、文件比对、WAS 打包与历史、浏览器定位和相关前端。原有功能改动一并提交。本记录描述本轮检查，不将此前审计文档中的真实数据库验收视为本轮复测。

## 已修复的问题

- **事务生命周期与失败恢复**：统一提交/回滚清理；请求超时约束事务建立，成功建立后页签事务不随 HTTP 请求结束而回滚；连接重试不清除其他页签事务，事务内查询不透明重试；批量失败整体回滚，前后端一致反映待提交状态。
- **SQL 脚本结构与参数绑定**：共用词法扫描处理注释、普通字符串、Oracle q 引号和 PL/SQL 分隔；执行前验证整个脚本参数，位置参数跨语句连续绑定；阻止脚本内事务指令绕开工作台事务控制，识别带注释的存储代码 DDL。
- **网格写入与页签隔离**：统一使用类型化网格接口，依据实际执行 SQL 与原始结果定位表/记录，保留 NULL 与空白原值；Oracle ROWID 同样使用原值并发校验；编辑器改写、切换页签或异步响应不改变写入目标，暂存队列按上下文隔离。
- **完整文件导入**：提交原始文件后由后端重新解析，消除仅导入预览行、CSV 表头误入库等问题；校验文件大小和行数；精确小数以十进制字符串绑定，Oracle DATE 保留时间，XLSX 保留富文本并拒绝越界单元格。
- **文件比对复制**：复制流结束、目标发布前再次校验源版本与字节数，源变化时保留旧目标；修复 Windows 卷根允许路径判断。
- **打包发布**：统一单包/批量产物发布流程，预检全部产物；clean-owned 不覆盖未归属的同名文件，保留失败恢复所需备份。
- **前端资源加载**：发布版默认使用内嵌资源，通过显式 `--web-dir` 开启本地开发资源，避免工作目录中的旧文件替换发布版页面。
